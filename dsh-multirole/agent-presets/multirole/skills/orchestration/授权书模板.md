# 授权书

> 全授权模式的唯一生效依据。口头声明无效。人可随时一句话撤销，即时生效。
> 落盘位置建议：项目目录 `授权书.md`；总控每次决策前核对本文件存在且在有效期内。

- 模式：全授权
- 被授权人：顾问
- 签署人（人）：
- 生效日期：
- 失效条件：（日期 / 阶段结束 / 人书面撤销，先到为准）

## scope（委托顾问裁决的事项）

- [ ] 任务单批准
- [ ] 规格终审（pattern/阈值/正则等精确规格的批准版）
- [ ] 验收裁决（含打回/返工裁定）
- [ ] 席位与模型调度
- [ ] （项目自定义项……）

## reserved（永远保留给人，内置默认，可加项不可减项）

1. 消耗人专属资源（账号登录态、付费确认、对外发送/发布）
2. 不可逆操作（删除非产出物、推送远端、覆盖无备份文件）
3. 变更模式自身（preset、流转协议、本授权书）
4. 叫停权本身

## 自动降级

顾问裁决引发的同类事故满两次（以裁决日志为准），该决策类别自动从 scope
移回 reserved，总控执行降级并报告人，无需人再签一次。
