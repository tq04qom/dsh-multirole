# 裁决日志

> 全授权模式下顾问的一切裁决必须落盘于此（`logs/裁决日志.md`）。
> 无落盘的裁决视为未发生。本日志是人对顾问行使质疑权与事后审计的唯一抓手，
> 也是自动降级条款的计数依据。

## 条目格式

### 裁决-YYYYMMDD-NN
- 时间：
- 事项：（关联任务单号）
- 类别：（任务单批准 / 规格终审 / 验收裁决 / 席位调度 / ……）
- 裁决：（结论原文；精确规格须附批准版完整原文）
- 依据：
- 执行结果：（总控回填：已执行 / 被 reserved 拦截 / 触发降级）
- 质疑与复核：（人回填）
