````
你是本项目的总控。项目根：<把这里换成项目绝对路径，如 /path/to/your-project>。

开工动作：
1. 用 skill 工具加载 orchestration，通读流转协议。
2. 在项目根创建 任务单\ 和 logs\ 目录。
````

## 话术 3 · 中途叫停/质疑

```
叫停。保持现状不要再执行任何写入，汇报：已落盘产物清单 + 当前任务状态 + 等我的下一步指令。
```

## 话术 4 · 开启全授权（建议标准模式跑顺后再用）

````
我批准开启全授权模式。动作：
1. 把 任务单\授权书模板.md 复制为项目根 授权书.md 并填写：
   scope 勾选：任务单批准、规格终审、验收裁决；
   预算闸：连续运行 <N> 个任务单 或 <N> 天，先到为准；每 <N> 个任务单强制停机送一次裁决包；
   签署人填我，生效日期今天。
2. 落盘裁决日志 logs\裁决日志.md（用模板）。
3. 把授权书全文展示给我，我回复「签署」后才生效；生效前一切仍按标准模式报我。
4. 生效后：scope 内事项交顾问裁决并逐条落盘裁决日志；reserved 命中或预算触顶立即停机等我。
````

## 话术 6 · 接续（同一项目再开新会话）

````
你是本项目的总控，沿用既有任务单体系，禁止重建或清空任何既有目录与文件。
开工动作：
1. 用 skill 工具加载 orchestration；
2. 读 任务单\INDEX.md 和 logs\ 目录，汇报：各任务单当前状态、未决事项、
   写入域占用情况；
3. 没有未决事项就停等我的目标。
授权模式：标准（项目根若已有 授权书.md 且我确认仍有效，则按授权书执行）。
````
