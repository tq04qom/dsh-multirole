# 验收清单（总控每次验收逐项过，逐项留证）

> 机判全绿 ≠ 完成。标准模式下终审报人；全授权模式下由顾问按本清单裁决。
> 每一项须在裁决包中附证据（命令 + 实际输出摘要），空口打勾无效。

## 固定项（任何任务单全过）

- [ ] A1 产出物齐全：任务单「产出物」清单逐项存在（ls 自证，绝对路径）。
- [ ] A2 写入域合规（正向）：全部产出落在任务单写入域内。
- [ ] A3 写入域合规（反向）：写入域外无新增/修改文件（目录树比对或 git status；
      发现域外变动即越界，无论质量一律打回）。
- [ ] A4 验收标准逐条亲验：任务单每条验收标准，总控亲自执行验证并记录
      实际输出；禁止凭执行者自述通过。
- [ ] A5 不做的事核查：任务单「不做的事」所列方向/文件确认未被触碰。
- [ ] A6 prompt 存档：生成类任务，实际 prompt 全文（含系统提示与全部注入
      字段的最终形态）随产出物落盘；无存档 = 未交付。
- [ ] A7 幂等复跑：批量任务原样复跑一次，无重复副作用、已处理项被跳过。
- [ ] A8 遗留问题：执行者报告的 FATAL/遗留问题已全部记录且有处置结论
      （解决 / 转新任务单 / 报人），无悬空项。
- [ ] A9 索引回填：验收通过后 INDEX.md 回填「实际结果」并流转状态。

## 判据

- A1–A9 全过 → 机判合格，出裁决包进入终审。
- 任一项不过 → 打回，任务单写明打回理由（引用本清单项编号），状态回「打回」。
- 同一任务连续 3 次打回 → 触发停机条件，报人。
